Frequently asked

What is Project-X?

A clean starting point — a static site scaffold you can shape into a product, a portfolio, or a landing page.

Do I need a build tool?

No. It's plain HTML, CSS, and a touch of vanilla JavaScript. Open index.html and you're running.

How do I deploy it?

Push the files to any static host — GitHub Pages, Netlify, Vercel, or an S3 bucket. No server required.

Ready to start?

Clone it, rename it, make it yours.
